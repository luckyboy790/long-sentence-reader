# 长难句精读

一款可以直接在浏览器里运行的英语长难句阅读工具。先自己找主语和谓语，再切换到「只看主干」，逐层查看从句、修饰关系和参考译文。支持电脑和手机。

## 运行

下载项目后，保留 `index.html` 与 `assets/` 的相对位置，双击 `index.html` 即可使用。项目使用原生 HTML、CSS 和 JavaScript，无须安装依赖或构建。

也可以在本目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。自定义句子、笔记、词组和掌握进度保存在当前浏览器中，建议固定使用同一地址。

## 从自己的句子开始

1. 选择「添加新句」，粘贴英文原句。来源和已有译文均可选填。
2. 选择「已有 AI 对话」，复制指令和原句，发给常用的 AI，再将完整回复粘贴回网页。也可切换到「DeepSeek API」，使用自己的密钥直接发起解析。原句和解析指令会发送至 DeepSeek，使用个人 API 额度。页面不会保存密钥。
3. 预览主干、逐层拆解、重点词组和译文，再选择「保存并精读」。页面会核对英文引文的位置；涉及语法或语义判断的内容，可在「校订解析」里修订。
4. 在阅读页收藏词组，按知识点做专项练习，或标记「已掌握」后到学习手册复习。

## 维护与扩充

- `assets/sentences.js` 收录四句原创示例，按考研英语一、英语二、四级、六级划分练习方向。可仿照现有记录添加拥有发布权的句子。每条记录包含英文、主谓和主干引文、译文、结构讲解及词组。英文引文按大小写与标点匹配原句。
- `assets/reader.js` 和 `assets/reader.css` 负责阅读、练习、收藏与响应式界面。
- `assets/personal.js` 和 `assets/personal-ui.js` 负责个人句库、编辑与本地保存。
- `assets/ai-analysis.js` 包含解析提示词、返回格式校验、预览和 DeepSeek 请求逻辑。
